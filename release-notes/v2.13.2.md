Obsidian Edition 2.13.2: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). The creation screen rolls a new character's age on the Dark Sun rules' dice with each roll of the die, and Restore Youth can take back any number of magical years.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.13.2.zip`** below and unzip it anywhere. (Updating: to keep your options, copy `settings.json` from your old folder into the new one. Your saves and characters are in the game folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.13.1

**Changed**
- **A new character's age is rolled.** With *Ages and magical aging* on, the age above RECALL on the creation screen is the race's starting age with Table 7's dice rolled for real (a human's 15 + 1d8, a dwarf's 25 + 4d6...), again with each roll of the die and each choice of race, sex or class. Changing a score keeps it, and **STORE** and **RECALL** keep it with the rest of the roll. **DONE** keeps it with the character. (It was worked out from the name and race, so the die never changed it.) The game's own party gets real rolls too.
- **Restore Youth has no limit** on the magical years it can take back: each character's starting roll is now kept with it, so its true age is always known, however many years Haste has added.

## Your saved games

**A save made with 2.13.2 is not for 2.13.1 or earlier.** Each character's starting roll is kept beside its weapon specs, which an older Loader reads as other specs. Older saves load in 2.13.2 as they are: a character who already has an age keeps it, and the roll it came from is kept with it when the game is loaded.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
