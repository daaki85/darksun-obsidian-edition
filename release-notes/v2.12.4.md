Obsidian Edition 2.12.4: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). The Loader can now run the game as Dark Sun Recompiled instead of in DOSBox.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.12.4.zip`** below and unzip it anywhere. (Updating: to keep your options, copy `settings.json` from your old folder into the new one. Your saves and characters are in the game folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.12.3

**Dark Sun Recompiled**
- **The Loader can run the game without DOSBox.** [Dark Sun Recompiled](https://github.com/daaki85/darksun-recompiled) is the game translated into a program of its own, with the mod's patched game and helper built in. Unzip its `darksun-recompiled-windows-x64.zip` into the mod's folder (or next to it), and **Start the game** runs it instead of DOSBox from then on, with the dice log and the Loader's window following the game as usual.
- **Which one runs is always said.** As the game starts, the dice log says `... in DOSBox` or `... as Dark Sun Recompiled` and where it is.
- **A program elsewhere is named once** with `dsloader launch --recompiled "C:\path\to\dsun.exe"`; `dsloader launch --dosbox` goes back to DOSBox.
- The game's own `DSUN.EXE` is never taken for it, even with the mod unzipped in the game's folder.
- Without Dark Sun Recompiled, nothing changes: the game runs in DOSBox as before.

Details are in [`obsidian-edition/README.md`](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.12.4/obsidian-edition/README.md) under "Other ways to start".

## Your saved games

Saves are the game's own, so they work in DOSBox and in Dark Sun Recompiled alike.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
- Dark Sun Recompiled is optional.
