Obsidian Edition 2.7.1: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). A small release after 2.7.0. Wake of the Ravager's art is now found where GOG Galaxy installs it, and the dice log names what a monster's special attack does. It is pull request #57.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.7.1.zip`** below and unzip it anywhere. (Updating: to keep your options, copy `settings.json` from your old folder into the new one. Your saves and characters are in the game folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.7.0

**Fixed**
- **Wake of the Ravager's icons and pictures with GOG Galaxy.** GOG sells Wake of the Ravager with Shattered Lands, and the 6th-level priest spells use its art, read from your copy. Galaxy installs the two games as `Dark Sun` and `Dark Sun 2`, but the Loader only looked for a folder with "Ravager" in its name, so a Galaxy install got the Loader's own icons instead. The Loader now checks:
  - every folder beside Shattered Lands;
  - GOG's usual install folders on every drive;
  - one folder down inside each of those.
- **The Loader finds Shattered Lands in GOG Galaxy's `Dark Sun` folder** without being shown where it is.

**Added**
- **A Wake of the Ravager section on the Options tab.** It says where the Loader found the game, or that it didn't. **Choose its folder...** points the Loader to a copy installed anywhere else (from the next start of the game).
- **What a monster's special attack does, in the dice log.** The game has no names for monsters' special attacks, so the log showed only a number. It now names them by what they do, such as a Paralysing, Disease, Entangling or Poison attack, or a Fire attack (6d6 fire). It also says that the dice rolled before the saving throw are how long the effect would last. The Red Slaad's line used to read `special attack 182: 2d4 = [4 + 3] = 7`. It now reads `Paralysing attack: lasts 7 rounds unless saved against (2d4 = [4 + 3] = 7)`.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
