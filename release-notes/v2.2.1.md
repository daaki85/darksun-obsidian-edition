Obsidian Edition 2.2.1: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox), with its companion window, Templar's Ledger. More of the Options tab can be switched, and it can be set back to its defaults. It is pull request #43.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.2.1.zip`** below and unzip it anywhere. (Updating: to keep your options, copy `settings.json` from your old folder into the new one. Your saves and characters are in the game folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Ledger's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Ledger follows it.

The game's own files are never changed. The Ledger runs a patched copy of the game from its own folder.

## What's new since 2.2.0

- **New switches,** each on by default and counting from the next time the game is started:
  - **Elves have pointed ears, and half-elves figures of their own** (Graphics). Off, elves are as the game draws them and half-elves are the human figures in their own colours.
  - **Cilla drawn as an elf** (Graphics). Off, she keeps the half-elf woman's figure the game gives her.
  - **STORE and RECALL on the creation screen** (More character customization). Off, the creation screen is the game's own.
- **Restore defaults** at the bottom of the Options tab sets every switch back, after asking.
- **Clearer Options headings:** plain names, with one line above them saying that everything applies in games started from the Ledger, and that a switch marked "from the next start" waits until the game is started again.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
