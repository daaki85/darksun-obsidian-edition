Obsidian Edition 2.16.1: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). Fixes to looting, selling, thieves' locks and saved games' named copies, and clearer documentation: every Options switch in one table, a shorter README and a better Help page.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.16.1.zip`** below and unzip it anywhere. (Updating: copy `settings.json` (your options) and the `Named saves` folder (your saves' named copies, and any `Replaced -` copies a restore kept) from your old folder into the new one. Your saves and characters are in the game folder, or its `cloud_saves` folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.16.0

**Fixed**
- **Selling with S** pays for each item as it goes, so gear can never leave the backpack unpaid.
- **Looting with T:** Caps Lock no longer swaps T and Shift+T, and a second body's T, pressed before the first was taken, is held instead of replacing it.
- **A thief's failed lock** is remembered by the lock itself, so the retry rule (with **Thieves as in AD&D**) always bars the right lock.
- **Named saves:** a backup put back in a slot with its old date is copied too, so the named folder always matches the slot.

**Documentation**
- The player's guide lists **every Options switch in one table**: its label, its default, when it takes effect and where to read more.
- The Loader's option texts are shorter, the README's overview is a page of links, and its update and backup steps name the **Named saves** and `cloud_saves` folders.
- The **Help** page has the guide's full contents and working links to the other pages.
- The patch notes are now **Changes from the original game**, with a summary at the top.
- New pictures of the combat log in its present font, and of the Loader's window.
- A correction to 2.16.0's notes: a merged switch keeps your choice only if both old halves agreed; if one was on and one off, it starts off, so tick it again if you want it.

Smaller fixes are in the [changelog](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.16.1/CHANGELOG.md).

## Your saved games

Saves and settings from 2.16.0 carry over as they are.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Optional: Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
