Obsidian Edition 2.17.1: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). Corrections to the documentation after an audit of 2.17.0, which brought psionic powers picked when you make a character and the player's manual in the download.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.17.1.zip`** below and unzip it anywhere. (Updating: copy `settings.json` (your options) and the `Named saves` folder (your saves' named copies, and any `Replaced -` copies a restore kept) from your old folder into the new one. Your saves and characters are in the game folder, or its `cloud_saves` folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Optional: Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.

Full details are in the manual, in [`obsidian-edition/README.md`](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.17.1/obsidian-edition/README.md) and [`obsidian-edition/FEATURES.md`](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.17.1/obsidian-edition/FEATURES.md).
