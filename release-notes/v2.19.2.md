Obsidian Edition 2.19.2: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). One fix after 2.19.1: F10 does nothing for a held or stuck character.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.19.2.zip`** below and unzip it anywhere. (Updating: copy `settings.json` (your options) and the `Named saves` folder (your saves' named copies, and any `Replaced -` copies a restore kept) from your old folder into the new one. Your saves and characters are in the game folder, or its `cloud_saves` folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.19.1

**Fixed**
- **F10 and a held character.** F10, the game's key that takes a move back in a fight, used to move a Paralyzed or Stuck character back to where its turn began (2.19.1 already stopped it walking from there). Now F10 does nothing for such a character: it stays where it is, with the movement it had. F10 for anyone else is unchanged.

What 2.19.0 and 2.19.1 brought is in [2.19.0's notes](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.19.2/release-notes/v2.19.0.md) and [2.19.1's](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.19.2/release-notes/v2.19.1.md); smaller changes are in the [changelog](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.19.2/CHANGELOG.md).

## Your saved games

Saves and settings from 2.19.0 and 2.19.1 carry over as they are. Coming from 2.18.0 or earlier, read [2.19.0's notes](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.19.2/release-notes/v2.19.0.md#your-saved-games) first: several rules became always on there.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Optional: Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
