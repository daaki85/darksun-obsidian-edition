Obsidian Edition 2.7.2: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). A small release of fixes after 2.7.1, most of them to the 6th-level priest spells. It is pull request #59.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.7.2.zip`** below and unzip it anywhere. (Updating: to keep your options, copy `settings.json` from your old folder into the new one. Your saves and characters are in the game folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.7.1

**Fixed**
- **Sunstroke ends the caster's turn.** After casting it, the caster's turn went on, as if the spell waited for more targets. Now it passes to the next in line, as for any other spell.
- **Wall of Thorns counts a monster's armour.** It does 8 plus the creature's AC, but took 10 for any armed man, whatever he wore. It now counts the armour and shield he wears, his DEX and a gladiator's levels, as the game does for an attack: Scar, in leather arm and chest armour with DEX 17, takes 13, not 18.
- **The Look box gives a monster's real AC from the start of a fight.** Before anything had attacked a monster, its AC in the Look box ignored what it wore (Scar's said 10). Now it's the AC the game uses against it (Scar's: 5).
- **Heartseeker's and Slay Living's descriptions.** A creature that saves still takes 2 to 16 (half of 4d8): Heartseeker's description left that out, and the game's own text for Slay Living said 3 to 17.

**Changed**
- The helper that runs inside the game uses less memory: room for more of the mod's code in the game's upper memory, where it doesn't cost the game any.

## Your saved games

Every fix works from the moment a save is loaded.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
