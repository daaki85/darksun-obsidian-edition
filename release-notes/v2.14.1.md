Obsidian Edition 2.14.1: a mod for **Dark Sun: Shattered Lands** (the GOG release, in DOSBox). Each class's least scores at creation are the manual's, high prime requisites earn the 10% more XP the manual promises, and bows the Loader gave shoot again.

## Getting started

1. Download **`Dark-Sun-Shattered-Lands-Obsidian-Edition-2.14.1.zip`** below and unzip it anywhere. (Updating: to keep your options, copy `settings.json` from your old folder into the new one. Your saves and characters are in the game folder, so nothing else needs moving.)
2. Double-click **`Start Obsidian Edition.bat`**. The first time, it offers to install 64-bit Python if you don't have it.
3. On the Loader's **Options** tab, pick the changes and additions you want. They're remembered.
4. Press **Start the game**. The game starts with your options, and the Loader follows it.

The game's own files are never changed. The Loader runs a patched copy of the game from its own folder.

## What's new since 2.14.0

**Fixed: the game's own bugs**
- **The creation screen's least scores are the manual's.** The game raised a class's prime requisite to 17 and every other score to one minimum (9 to 14), so a fighter's STR was never below 17 while a druid's CHA and a ranger's STR and DEX had no minimum at all. Now each class asks what the manual asks: cleric WIS 9; druid WIS 12, CHA 15; fighter STR 9; gladiator STR 13, DEX 12, CON 15; preserver INT 9; psionicist CON 11, INT 12, WIS 15; ranger STR 13, DEX 13, CON 14, WIS 14; thief DEX 9. A character of several classes takes the highest of theirs.
- **10% more XP for high prime requisites,** which the manual promises and the game never gave: for a class whose prime requisites are all 16 or more (a fighter's STR; a ranger's STR, DEX and WIS; a druid's WIS and CHA; a psionicist's CON and WIS). A character of several classes has one XP for them all, so each class with the bonus adds 10% divided by the classes: a fighter/thief with both 10%, with one 5%. The character's own scores count, not an item's or a spell's. The Loader adds it as each award comes, and the dice log shows it: `XP: Gerakis +660 (+60 for Gladiator, STR 24)`.
- **The game's Great Axe +3 had no material,** so its name showed none and no sphere's cleric could wield it under the class restrictions. It is metal now, as its icon shows.

**Fixed: the Loader's own**
- **A bow the Loader gave couldn't shoot** until it was taken off and put on again: a new character's whose weapon spec is the bow (any class), a Myrmidon's second spec's, a Battle Dancer's or Spellarcher's starting bow, and a Spellarcher's spell arrows made in an empty quiver. Bows and arrows already misplaced in a saved game are put right by themselves, out of a fight ("Yilballa's Bow is now held, ready to use").
- **Changing the leader just after a fight rolled a thief's hiding** (and printed a turn) as if the fight went on. It only happens in a fight now.
- **A melee weapon's item box read "0.5x1D8-1",** a half attack a round, whoever held it. It shows the damage alone again.
- **On the creation screen the dice log showed XP** each time the class changed ("XP: SeanBoy +1500"). It no longer does.
- The Options tab's switch for the new spells is called **New spells**: it covers the six wizard spells and the ten 6th-level priest spells.
- The helper (DSCLOG) has 1.7 KB more room for what comes next, with no change in the memory the game has.
- Smaller fixes are in the [changelog](https://github.com/daaki85/darksun-obsidian-edition/blob/v2.14.1/CHANGELOG.md).

## Your saved games

Saves from 2.14.0 load as they are, and saves made with 2.14.1 load in 2.14.0. The XP bonus starts with the next award; XP already earned isn't topped up. The new least scores apply to characters made from now on.

## Requirements

- Windows, with the GOG release of Dark Sun: Shattered Lands.
- 64-bit Python 3.8 or later. The `.bat` files offer to install it.
- Optional: Wake of the Ravager, which GOG sells with Shattered Lands, for its icons and pictures for the new priest spells. Without it, the Loader uses its own.
