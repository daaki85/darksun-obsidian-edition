The game's bugs, fixed

Part of Obsidian Edition's documentation, from Features and rules. Spoilers: some of these name places and people from later in the game, most of them under People and quests.

The patched game mends these whatever the Options tab says. The rules the game got wrong are further down. The script bugs are mended in the Loader's copy of the game's scripts; many were found by yuan-ti and the OpenDS project (credits). How the fixes work: DEVELOPMENT-CONTENT.md (the script bugs, the spells, worn items), the memory fixes in DEVELOPMENT-INTERNALS.md, and the rows' own links.

Making and keeping characters

BugThe gameWith the Loader
DELETE in the rosterDeleted the character in the row clicked counting from the top of the list, not from the top of what was shown, so with the list scrolled down another character was deletedDeletes the one chosen (how)
The creation screen's least scoresThe class's prime requisite raised to 17 and every other score to 9 to 14, against the manual: a fighter's STR never below 17, a thief's CHA never below 9, while a druid's CHA, a ranger's STR and DEX and a psionicist's CON had no minimum of their ownThe manual's: each class's, and a multiclass character the highest of its classes' (the minimums, class by class)
XP for high prime requisitesNone, though the manual promises 10% more XP to a class whose prime requisites are all 16 or more10% more of every award for each such class, divided by a multiclass character's classes (one XP for them all); a human's class followed now. The Loader adds it as each award comes, so it needs the Loader following the game (Experience and levels)

Rules it got wrong

Most of the mod's rule changes put right a rule the game gets wrong: they are listed with the rule changes, as rules the game got wrong. Each is always on, with no switch, as are the mends of two more of its bugs: Cilla's figure, and a click on a spell's icon on the Effects screen ending the spell.

Saved games

There's no need to start a new game for these: they're in the patched game, not in a save, so they work from the moment a game is loaded. What a bug already did stays in the save: your saved games says more.
