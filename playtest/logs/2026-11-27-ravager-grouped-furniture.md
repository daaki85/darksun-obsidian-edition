# Forest dining sets, Alliance vase and Mines 3 throne

Loaded the Roost save in DOSBox on a private copy of Ravager. Used the Reyhan test jump to reach the Forest and opened its overhead map. The camera stayed behind on arrival. Moving the pointer to a screen edge scrolled the scenery. The dining room did not appear in a verified game capture. This visit did not establish a water source.

Checked the file path separately in DOSBox with the shipped DSCLOG2 helper installed. A DOS program opened the three original region names using ordinary read-only file opens and copied every byte it read. With all three Loader copies mounted, all three reads matched their built region files byte for byte. Repeating with only the helper mounted returned all three original game files.

Compared the built object and region files with the previous pass for all 38 Forest placements, the Alliance crate and both pieces of the throne. All 41 produced a visible difference in their room renders. The placement tables change 14 Forest seating coordinates, one Alliance vase coordinate and one Mines 3 throne coordinate. The assembled-room images use the first stored pose. Direct in-game inspection of the three assemblies and the Mines 3 scripted sequences remains open.
